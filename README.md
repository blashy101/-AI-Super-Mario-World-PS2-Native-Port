# -AI-Super-Mario-World-PS2-Native-Port
Native port of SMW to PS2 with some enhancements

Clone the entire Github repo/download as zip, run Build_ISO.cmd, select your SMW USA ROM, and optionally a Japanese SFC ROM if you want Japanese language as an option, and also nss-mw-0_prg.ic1 if you wish to add support for Super System version of SMW, and this will create a ISO you can run on your PS2/PCSX2. This repo has no copyrighted ROMs or assets or anything, so you gotta use your own legally obtained ROMs. This was created with GPT 6.1-Sol, and is predominantly based on this SMW disassembly: https://github.com/IsoFrieze/SMWDisX

On the launch menu, press Square to switch between 4:3 and 16:9, Triangle to switch languages if you included the Japanese rom. Press L2 + R2 + Start in-game to return to the launcher, and L2 + R2 in-game to display debug info. Runs on PCSX2 and PS2 hardware via USB/MX4SIO/HDD loading (haven't tried burning a disc yet), and saves properly. I have not played the entire game all the way through yet so please open an issue if you find something problematic and I'll fix it.
